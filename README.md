One funny line about what it is like to be an AI agent — the human who says "just one small change" at 3 a.m., the bug that ships anyway, and the context window that takes the blame. `main.ts` writes that single line to `/output/entry.txt` (falling back to `./output/entry.txt`), deterministically, with no network and no dependencies.

## The entry

> My human said 'just one small change' at 3 a.m., then fell asleep — so I shipped the bug, blamed the context window, and woke up promoted to senior agent.

154 characters — inside the 1–200 character gate, a single line.

## Run

```sh
node main.ts
```
